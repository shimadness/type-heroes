# TYPE HEROES 〜みんなでタイピングクエスト〜

チームで協力してステージをクリアしていくタイピングRPG。
正しい打鍵で敵にダメージ、ワード完了で大ダメージ。攻撃と回復を切り替えながら、
みんなで「はじまりの森」→「こだまの洞窟」→「まおうの城」を攻略する。

## あそびかた

- **へやをつくる**: あいことば（パスワード）を決めて部屋を作る。なかまに教えて集合。
- **あいことばで参加**: 同じあいことばを入れれば同じ部屋に入れる。
- **ひとりで特訓**: 通信なしのソロモード（Firebase不要）。
- **観戦する**: あいことばを入れると戦闘をリアルタイムで見られる（社内モニター向け）。

### 戦闘

| 操作 | 効果 |
| --- | --- |
| タイピング | 1打鍵ごとに敵へダメージ（回復モードなら微回復） |
| ワード完了 | かな数に応じた大ダメージ / 大回復。ノーミスなら会心1.5倍 |
| Space | ⚔️こうげき / 💚かいふく 切り替え |
| Tab / クリック | ワードカード切り替え |
| 敵をクリック | ターゲット変更 |

- **弱点ジャンル**: 敵ごとに弱点（たべもの・どうぶつ等）。一致ジャンルのカードで2倍。
- **防御タイピング**: 敵の攻撃予告中に赤いカードを打ち切るとダメージ半減。
- **コンボチェイン**: 仲間のワード完了から3秒以内に完了すると火力ボーナス（最大+50%）。
- **ユニゾンアタック**: ゲージ満タンで発動。全員が同じ長文を時間内に打ち切ると超ダメージ。
- **蘇生**: 気絶した仲間は「そせいワード」を打ち切ると復活。全滅のみゲームオーバー。
- **ボス**: 怒りゲージ満タンで全体攻撃。インク隠し・カードシャッフル・カタカナ化などの妨害ギミック。
- **ロール**: アタッカー / ヒーラー / タンク / バッファー。
- **ハンデ**: 出題難易度は1人ずつ設定可能（敵の強さは部屋主の難易度）。
- **装備ドロップ**: ステージクリアで1人1つ（剣・杖・盾・ブーツ）。
- **称号**: リザルトでMVP・守護神・正確王など全員に称号。
- **ランキング**: クリアタイムのチームTOP10（難易度別・全端末共有）。

## 開発

```bash
npm install
npm run dev    # 開発サーバー
npm run build  # 型チェック + ビルド（dist/）
```

## Firebase（マルチプレイ）

- RTDB は TWINKLE DROP RUSH と同じ `triple-slot-ranking` プロジェクトを共用。
- パス: `typing/rooms/{あいことば}` / `typing/ranking/{難易度}`
- **初回のみ**: `docs/rtdb-rules.json` の内容を Firebase コンソール > Realtime Database > ルール に貼り付けて公開すること（`typing` ブロックが追加されるまでマルチプレイは動かない。「ひとりで特訓」は動く）。

## 実装メモ

- ローマ字判定: `src/typing/romaji.ts`。複数入力パターン（si/shi、っ=子音重ね/xtu、ん=n/nn 等）を並列ステートNFAで受理。
- 同期: ホスト（部屋主）クライアントが敵AI・進行を担当（`src/game/host.ts`）。打鍵判定は各クライアントローカル、ダメージはRTDBトランザクションで反映。ホスト切断時は参加が最も早いプレイヤーが自動引き継ぎ。
- `src/net/store.ts` の Store 抽象で Firebase / ローカル（ソロ）を差し替え。
