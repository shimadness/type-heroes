# TYPE HEROES あそびかた（配布用）

**https://shimadness.github.io/type-heroes/**

スマホ・PCどちらのブラウザでも動きます（インストール不要）。
タイピングするのでPCのキーボード推奨です。

---

## 1. あつまる

1. だれか1人が **「🏰 へやをつくる」** →「あいことば」を決める（例: `kaisha1`）
2. ほかの人は **「🤝 あいことばで参加」** → 同じあいことばを入れる
3. 全員が **「じゅんびOK！」** を押したら、部屋主が **「⚔️ ぼうけんに出発！」**

見るだけの人は **「📺 観戦する」** であいことばを入れればOK（大画面に映すと盛り上がります）。

## 2. ロールを選ぶ

| ロール | 役わり |
| --- | --- |
| ⚔️ アタッカー | ダメージ1.25倍。とにかく敵を削る |
| 💚 ヒーラー | 回復量1.6倍。みんなのライフを守る |
| 🛡️ タンク | 狙われやすいが被ダメ35%カット |
| 🎺 バッファー | ワード完了で8秒間チーム火力+20% |

**ヒーラーが1人いると安定します。** 4人なら全ロール揃えるのがおすすめ。

## 3. 難易度は2種類ある

- **てきの強さ（チーム難易度）**: 部屋主が決める。全員共通
- **じぶんの出題難易度（ハンデ）**: 1人ずつ変えられる

タイピングが苦手な人・お子さんは自分だけ「かんたん」にできます。
同じ部屋で大人が「おに」、子どもが「かんたん」でも一緒に遊べます。

## 4. たたかいかた

| 操作 | すること |
| --- | --- |
| キーボードで入力 | 1打鍵ごとに敵にダメージ |
| **Space** | ⚔️こうげき ／ 💚かいふく の切り替え |
| **Tab** | 打つワードカードの切り替え |
| 敵をクリック | ターゲット変更 |

### 勝つためのコツ

- **⚡弱点をねらう** — 敵ごとに弱点ジャンルがあり、金色のバッジが付いたカードを打つと
  雑魚2.5倍・**ボスは3.5倍**。速く打つより弱点を選ぶほうが強い
- **🛡️赤いカードは最優先** — 敵の攻撃予告。打ち切ればダメージ半減
- **🔗チェイン** — 仲間のワード完了から3秒以内に完了すると火力ボーナス（最大+50%）。
  「いくよ！」と声を掛け合うと繋がる
- **✨ユニゾンアタック** — ゲージ満タンで発動。全員が同じ長文を時間内に打ち切ると大ダメージ。
  1人でも間に合わないと不発なので、発動タイミングは声かけを
- **⛑️そせい** — 仲間が気絶したら緑のカードを打って復活させる。全滅しなければ負けない
- **💢怒りゲージ** — ボスのゲージが満タンになると全体攻撃。溜まる前に削るか、回復で備える

## 5. 終わったら

- クリアタイムが **🏆ランキング**（難易度別・全端末共有）に登録されます
- リザルトでは全員に称号が付きます（MVP・守護神・正確王・コンボ王・鉄壁・救世主）
